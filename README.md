# UniQuest 🎓✨

UniQuest is a web application designed to help university students find part-time jobs, internships, and industry opportunities. It connects students with companies, providing an easy-to-use platform for discovering roles, applying, and receiving feedback.

## 🚀 Project Overview

This project was developed as part of our second-year group project at the University of Colombo School of Computing (UCSC). The system aims to:

- Help students explore part-time jobs and internships.
- Provide companies a platform to post job opportunities.
- Allow students to create and manage their profiles.
- Enable communication between students and companies.
- Support reviews and feedback for companies.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Other tools:** Bootstrap, jQuery, AJAX

## ✅ Project Completeness

We are proud to report that **100% of the planned functionalities** from our proposal have been completed — with several extra features added along the way.  

### 🧑‍🎓 Student Features (Highlights)
- Register, login, logout, forgot password.
- Search, filter, sort jobs and internships.
- Apply, track applications, save posts.
- Rate, review, edit/delete reviews (including anonymous).
- Communicate with companies and admin.
- Receive notifications and manage profile.

### 🏢 Company Features (Highlights)
- Register, login, logout, forgot password.
- Post, edit, deactivate, delete jobs.
- Customize job application forms and fields.
- Manage and track applications.
- Activate premium plans for advanced features.
- Access analytics, generate/download reports.
- Communicate with students and admin.

### 👨‍💼 Admin Features (Highlights)
- Login, logout, forgot password.
- Approve/reject users, jobs, internships.
- Manage complaints, send notifications/messages.
- Add/manage verification team members.
- View platform analytics, generate/download reports.
- Update application settings (reasons, industries).

### 🛡 Verification Team Features
- Login, forgot/change password.
- Approve/reject users and job posts.
- Communicate with admin.
